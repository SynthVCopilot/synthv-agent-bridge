## 5. 新发现的缺陷与阻塞项

### D-001 — 默认 `get_track_notes` 泄漏嵌套 main Group UUID

- 等级：**Important / Stage 1 blocker**
- 证据：默认、read-only、未显式请求诊断字段的 `get_track_notes` 返回中，嵌套 Track
  对象包含 main Group UUID；报告未保存其原值。
- 合同冲突：交接文档、测试矩阵与 Phase 3 验收都把该 UUID 视为私有 locator metadata。
- 代码定位：[v3-surface.ts](../src/v3-surface.ts) 的 `get_track_notes` 嵌套 Track 清理只删除
  fingerprint 字段，没有删除 `mainGroupUuid`；当前测试只覆盖 `list_tracks` 的该字段。
- 影响：默认公共 Query 投影违反隐私/最小投影合同；Stage 1 privacy gate 失败。
- 建议最小修复：在嵌套 Track 清理中删除 `mainGroupUuid`，添加 public MCP 路径回归测试，
  同时断言 default/explicit fields/debug 均不会绕过删除。

### D-002 — `doctor` 对安装构建稳定误报

- 等级：**Important / reproducibility blocker**
- 证据：运行时三组件 matched；正式 `prepareExecutorSource()` / `prepareSidebarSource()`
  生成内容与安装文件逐字一致，但 `doctor` 报 executor、Sidebar 和 installed scripts 不匹配。
- 原因：[doctor.mjs](../scripts/doctor.mjs) 直接读取含
  `__SYNTHV_AGENT_*_BUILD_ID__` 占位符的仓库源，再与已注入真实 ID 的运行/安装文件比较；
  它没有复用 [component-build-identity.mjs](../scripts/component-build-identity.mjs) 的准备逻辑。
- 影响：正确安装无法通过交接第 12.3 节 doctor 门禁，容易触发无意义的重装/重载。
- 建议：让 doctor 复用 `readComponentBuildIdentity()`，比较生成后的组件内容与 Build ID，
  并增加真实占位符源 -> 已注入安装文件的回归测试。

### D-003 — Sidebar client status 持续记录 `EBUSY`

- 等级：**Important / Sidebar scenario blocked**
- 证据：连续两次 `sv_review(status)` 均为 fresh/running，但 `lastErrorCode=INTERNAL_ERROR`，
  错误为 Windows 上删除 Sidebar client-status 文件时 `EBUSY`；没有活动 task。
- 影响：本轮不能把 Preview/Apply 流程标记为健康通过。
- 建议：隔离复现状态文件原子替换/删除竞争，记录重试、文件所有者和最终一致性；在错误
  清除并通过一次 Preview/Apply/Undo 前，Sidebar 保持 experimental/blocked。

### D-004 — Ctrl+Z 注入不触发 SynthV Undo

- 等级：Advisory
- 证据：Ctrl+Z 后权威 Mixer 回读仍为 -3 dB；可见“编辑 -> 撤销”一次立即恢复 0 dB。
- 影响：远程/自动化恢复流程不能假设键盘快捷键成功；必须回读验证并准备菜单路径。

## 6. 未运行范围与原因

- 没有非主 Note Group、notes、Pitch Controls 或 Automation points，因此 shared Group、
  linked/isolated/shell clone、guarded note edit/delete/transform、Automation closed-range 和
  transaction 场景需要先造数据；
- D-001 已使 Stage 1 privacy gate 失败，D-003 又阻塞 Sidebar；按 stop-first 原则没有继续
  扩大真机写入范围；
- 未做 Vocal onboarding 或 `apply_group_tuning`；本轮没有调音写入，因此没有猜测 Vocal
  或 Vocal Mode；
- 未做 17 Query/9 UI/38 write 的 Stage 2 全覆盖；
- 未做 1,000 reads、200 write/Undo、clone/transaction 重复矩阵或四小时 Stage 3；
- 未测 tracing on/off 增量；
- 未测试 plugin/ARA、工程保存或音频导出，它们不属于本次 release scope。
